Connection & setup
The backend runs on this page’s origin. No X cookies belong in this browser.
Live mode: set AUTH_TOKEN and CT0 in the server’s private .env, only after consenting to use your session. See README. X cannot bypass blocked or expired access.
Demo: run npm run demo. Fixture posts are invented examples, not your timeline. Live errors never fall back to demo.
Loopback works on this computer only. Phone access requires an explicitly protected HTTPS origin, backend configuration and matching app manifest.




Privacy & diagnostics
Reading and explicit bookmark saves only. X credentials stay on the server. Feed text and reading position are cached locally in the Even host (bounded to 180k characters); no post text or handles are included in diagnostics. Clearing the cache removes the reader’s host copy, not the server session.
